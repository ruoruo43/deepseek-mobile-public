# DS 对话 Android 首版开发计划

**目标** 安装 APK 后输入 DeepSeek API Key，验证通过后进入对话。默认连接官方 API。

**底座** 固定使用 `deepseek-ai/chat-demo` 的 `cdf9617c5f265d58e0e1805635b2c10a3d41284d`，保留原 MIT 许可和已有对话功能。Android 容器通过 HTTPS 虚拟资源地址加载 APK 内的页面。

1. **配置与密钥**。使用官方模型列表接口验证 Key。Android 通过限定来源的消息通道读写密钥，使用 Android Keystore 中的 AES-GCM 密钥加密后保存在应用私有目录。验收错误 Key、模拟成功、重启恢复和浏览器存储检查。
2. **社区功能**。按官方模型能力提供 Flash 和 Pro。参照社区的自定义指令功能保存用户主动配置的指令，随对话发送，并让续写沿用原回复的指令。添加会话文字搜索、置顶与 Android 系统分享。使用测试数据验收模型选择、指令、搜索、置顶、分享和长对话边界。
3. **打包与核验**。打包本地资源，限制应用内请求目的地。检查锁定依赖、应用权限、包内文件和签名。用模拟 API 在 Android 模拟器执行主流程。交付签名 APK 和核验记录，再把源码与对应 APK 发布到已建私有仓库。

**来源** [官方 chat-demo](https://github.com/deepseek-ai/chat-demo) · [DeepsleepChat](https://github.com/NyaNyaMan/DeepsleepChat) · [Astra](https://github.com/Greenchannel/astra)

## 0.2.0 扩展

1. **手机界面**。用雾蓝底色、轻量分隔、深蓝标题和钴蓝主按钮建立一致的界面。连接页保留唯一的输入和验证动作。会话顶栏显示模型，首页给出三种可编辑的草稿模板。侧栏突出处于顶部的搜索与新对话，设置按通用、数据和 GitHub 更新呈现。
2. **检查更新**。配置单独的 GitHub 私库只读令牌后，原生层手动访问固定的最新发行接口。对照已安装版本，显示是否有更新并给出私有发行入口。
3. **覆盖升级**。沿用包名和签名，验证旧版测试密钥、对话和置顶在升级后可读取，再复核更新面板、签名和 APK 安全扫描。
